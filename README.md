# График смен — Android-приложение (Capacitor)

Учёт рабочих смен и заработка. Только календарь смен и подсчёт: часы, заработок, количество смен за месяц.
Работает офлайн, данные хранятся на телефоне. Есть синхронизация с Google Диском (с шифрованием),
импорт и экспорт (JSON, CSV) и резервные копии.

Из инструментов нужны только **VS Code и git**. APK собирает GitHub Actions.

## Как получить APK

1. Создайте на GitHub пустой репозиторий (можно приватный).
2. В папке проекта выполните:
   ```
   git init
   git add .
   git commit -m "График смен"
   git branch -M main
   git remote add origin https://github.com/<вы>/<репозиторий>.git
   git push -u origin main
   ```
3. Откройте вкладку **Actions** → запуск «Сборка Android APK» (идёт ~5 минут).
4. В конце запуска, в разделе **Artifacts**, скачайте `shift-schedule-apk`, распакуйте и установите `shift-schedule.apk` на телефон (разрешите установку из неизвестных источников).

Чтобы APK лежал в **Releases** (удобно качать с телефона): `git tag v1.0.0 && git push --tags`.

Все сборки подписаны одним и тем же ключом из репозитория (`android/app/shift-schedule.keystore`),
поэтому новая версия ставится **поверх** старой, данные сохраняются. Репозиторий лучше держать приватным.

## Google Диск (один раз, ~10 минут)

Вход сделан через «код устройства» (как на телевизоре): не нужны SHA-1, сервисы Google Play и свой сервер.

1. <https://console.cloud.google.com> → создайте проект.
2. **APIs & Services → Library** → включите **Google Drive API**.
3. **OAuth consent screen / Google Auth Platform**: тип **External**, название и ваш e-mail.
   Добавьте scope `.../auth/drive.appdata`. Затем **Publish app → In production**
   (иначе токен входа «протухает» через 7 дней; проверка Google для этого scope не нужна).
4. **Credentials → Create credentials → OAuth client ID** → тип **TVs and Limited Input devices**.
   Скопируйте **Client ID** и **Client secret**.
5. Впишите их в `www/js/config.js` — или оставьте пустыми: приложение само спросит при первом подключении
   и сохранит только на телефоне.
6. В приложении: **Меню → Подключить Google Диск** → придумайте пароль шифрования → «Открыть Google»
   (код копируется) → вставьте код, войдите и разрешите доступ. Дальше вход автоматический.

Данные лежат в скрытой папке приложения на Диске (в обычном списке файлов её нет) и зашифрованы
AES-256-GCM вашим паролем. Забыли пароль — облако не восстановить (данные на телефоне остаются).
Синхронизация идёт **только по нажатию**: данные объединяются по дате дня, при расхождении приложение спросит, какую версию оставить.

> Старый файл синхронизации прежнего веб-приложения приложение не увидит (другой клиент Google и другая папка).
> Перенесите данные через **JSON**: в старом приложении «Сохранить JSON», в новом — «Импорт из файла».

## Что внутри

```
www/                    веб-часть (HTML/CSS/JS без сборщика)
  index.html, css/app.css
  js/model.js           данные и расчёт смен
  js/calendar.js        календарь, итоги, выбор месяца
  js/editor.js          редактирование дня
  js/dataio.js          импорт/экспорт, резервные копии
  js/cloud.js           Google Диск: вход, шифрование, слияние
  js/menu.js, main.js, ui.js, native.js, icons.js, util.js, config.js
  js/vendor/capacitor.js   рантайм Capacitor (CI обновляет сам)
android/                Android-проект (иконки, тема, подпись)
resources/              исходники иконки (SVG) и генератор
.github/workflows/      сборка APK
capacitor.config.json   настройки Capacitor
```

Расчёт: `минуты = (конец − начало) + довоз`, `сумма = round(ставка/60, 2) × минуты` — как в прежнем приложении.
Смена учитывается в итогах после окончания (с довозом). Дни, загруженные из старых файлов, хранят свои прежние
минуты и суммы; изменённые в приложении — пересчитываются по текущей ставке.

Кнопка «Назад»: закрывает окно → возвращает к текущему месяцу → выходит. Свайп по календарю листает месяцы.

## Правки и сборка локально (необязательно)

Любое изменение в `www/` → `git push` → новый APK. Иконку можно перерисовать в `resources/*.svg`
и перегенерировать `python resources/generate-icons.py`.
